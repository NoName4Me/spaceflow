# 产品与业务规则

## 范围

Spaceflow 管理会议室资源，不管理会议参会者、议程或邀请。当前采用本地账号和部门；不包含真实照片上传、整层平面图、工位管理、SSO 或外部日历同步。

## 员工使用流程

1. 按楼栋、楼层、日期、时段、人数和设施筛选会议室。
2. 在宫格或列表中查看容量、布局、设施与时段状态。列表包含布局缩略图，展示方式会在当前浏览器保留。
3. 点击条目打开详情弹窗，查看布局、规则和预订记录，直接发起预订。
4. 在“我的预订”修改、改期、取消，或处理周期系列的后续预订；结果通过站内通知反馈。

界面只保留必要数据与操作，不重复显示页面大标题、颜色图例或说明性副标题。

## 智能找房与冲突替代

发现页支持一句话描述日期、时段、人数、设施及位置，模型解析后由后端查询实时空闲房间，最多返回 3 间。选择结果打开预订表单，确认提交时仍执行原有权限、审批及冲突校验。关键需求不明确时追问，当前仅处理同一天单次预订。

已选人数、设施、楼栋和楼层是硬约束：语言描述只能增加要求，不能降低人数、丢弃设施或更换已选位置。需要放宽时由用户调整筛选。语言中“优先某楼栋”仅影响排序。没有满足全部条件的房间，或该时段没有可订房间时明确提示，不自动换时间或推荐不符合条件的房间。

单次预订遇到冲突后，按当前筛选及表单时段查询替代房间；选择后保留表单内容，重新确认提交。周期预订沿用冲突日期预览，不自动替换。

未配置模型时仍可使用“按筛选推荐”和冲突替代；模型错误不产生猜测结果。模型只接收找房需求、当前筛选与用户可见的位置及设施目录，不接收预订详情。

## 空间与批量管理

空间层级为楼栋 → 楼层 → 会议室。楼栋和楼层支持新建、改名、排序及空节点删除；有下级对象时不能直接删除。会议室移动归属后保留原有预订。

会议室管理采用左侧层级树、右侧表格。可全选当前列表或勾选部分会议室，批量修改容量、面积、布局、设施、预订方式、开放状态、周期开关或所属楼层，单次最多 200 间。

批量编辑只更新勾选的属性；未选会议室、未选属性及原有权限保持不变。选择中有失效资源时整批回滚。统一修改后可再单独调整个别会议室。

## 共享布局

布局用于帮助选择会议室，容量独立维护，不按图中桌椅数量计算。

管理员在“布局管理”新增、复制或编辑共享布局，保留桌椅、屏幕和白板的编辑能力。支持拖动、缩放、旋转、网格吸附、撤销、JSON 导入导出和历史版本恢复。

每间会议室选择一个布局；发现页、缩略图和详情弹窗使用该布局预览。修改共享布局会同步影响所有引用它的会议室；个别房间需要不同布局时，先复制再分配。导入或载入历史版本后，点击保存才生效。

详情中的预订记录按使用日期与开始时间倒序展示，支持选日期及今日、明日、本周、本月快捷筛选；按每页 20 条加载。记录展示使用时间、会议主题、预订人、备注、提交时间与状态，限已确认和有效待审批预订。

## 预订与审批

- 业务时区固定为 `Asia/Shanghai`，开始和结束必须在同一天，全部时段限制在未来一年内。
- 每间会议室可配置直接预订、管理员审批或仅管理员预订，并独立决定是否开放周期预订。
- 周期支持每天、每周指定星期、每月同日及间隔，最多 52 次；不存在的月末日期跳过，不顺延。
- 冲突预览列出日期。默认整批提交；用户明确选择后可跳过已展示的冲突项。新出现的未确认冲突会阻止整批提交。
- `pending` 与 `confirmed` 占用时段。区间采用 `[开始,结束)`，相邻边界不冲突。
- 待审批占位到提交后 24 小时或预订开始，以较早者为准；后台每 10 秒检查，读取、创建和修改预订时也检查过期。
- 可修改尚未开始的有效预订。周期修改范围为本次，或选中项及之后的有效预订；日期和时间按统一差值移动，此前记录与已取消、跳过项不恢复。
- 改期或换房进入需审批的会议室后重新审批；仅修改文字不延长原占位期限。冲突或版本过期时整批回滚。
- 创建和修改预订支持最多 2000 字备注；旧预订默认无备注。
- 管理员代订归属所选员工，通知发给该员工，审计记录实际操作管理员。

## 权限、状态与隐私

可见与可订分别配置。未开启限制时默认全员允许；开启后允许人员和允许部门取并集，个人拒绝优先。管理员保留管理权限，但不能向停用或维护中的会议室创建预订。

| 状态 | 员工可见 | 接受新预订 |
| --- | --- | --- |
| 启用 | 按可见规则 | 按预订规则 |
| 停用 | 按可见规则 | 否 |
| 维护 | 按可见规则 | 否 |
| 隐藏 | 否 | 仅允许管理员按规则预订 |

状态、权限或归属变化不删除已有预订。预订者仍可查看与取消自己的申请；员工不能修改或取消他人的预订。

隐藏预订详情后，仅本人和管理员可读取主题、预订人、备注、联系人与联系方式；其他员工的接口响应只保留匿名占用信息。详情列表中显示“主题保密”，预订人和备注显示 `**`，敏感原文不发送到浏览器。

## 身份与通知

管理员可维护部门、账号、角色、状态和通知邮箱。停用、角色变更、重置密码会撤销账号会话；用户自行改密后重新登录。至少保留一个启用的管理员。

预订创建、修改、审批、取消与过期生成站内通知，支持已读状态；通知和操作记录各展示最近 100 条。配置 SMTP 后，后台队列向通知邮箱投递邮件；发送失败不会影响预订，最多重试 8 次。
