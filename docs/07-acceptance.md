# 当前版本验收 · 2026-10-24

## 验收入口

运行地址：`http://127.0.0.1:3080`。初始账号密码位于项目根目录 `.local-accounts`，修改后的密码以用户设置为准。

| 角色 | 验收路径 |
| --- | --- |
| 管理员 | 账号与部门 → 新增部门、账号、分配部门、停用与重置密码 |
| 管理员 | 会议室管理 → 新增档案 → 配置可见/可订部门或人员 → 开放周期预订 |
| 员工 | 空间发现 → 详情 → 单次/周期预订 → 我的预订 → 取消本次或所有后续 |
| 管理员 | 预订审批 → 逐次/系列通过或拒绝；预订管理 → 代订、取消 |
| 管理员 | 布局编辑器 → 修改 → 保存 → 刷新确认恢复 |
| 全员 | 通知 → 查看预订结果 → 全部已读；账号设置 → 修改密码重新登录 |
| 管理员 | 操作记录 → 查看操作者、动作、关联对象和时间 |

## 规则

- 可见与可订分别授权。未开启限制时全员可见/可订；开启后，允许人员与允许部门取并集；个人拒绝优先。管理员保留管理权限。
- 停用、维护时不接受新预订；隐藏会议室不出现在员工资源列表。状态与权限变更保留已有预订，预订者仍可查看和取消自己的历史申请。
- 待审批占位期限为 24 小时或预订开始时间，以较早者为准；后台每 30 秒回收，提交与读取时也主动回收。
- 预订时间使用 `Asia/Shanghai`，限制在未来一年内，同日结束。每天/每周周期支持 2—52 次；数据库存储每个实际时段。
- 周期创建采用单个事务。有冲突时全部回滚；用户可在预览后明确跳过冲突日期。提交过程中出现新的未确认冲突时，整批拒绝，不静默遗漏日期。
- 取消本次保留系列与例外关联；“取消所有后续”处理该系列当前时刻之后的有效预订。已发生的历史不受影响。
- 管理员代订的预订归属所选员工，通知发给该员工，审计记录实际操作管理员。
- 隐藏信息仅本人和管理员可读，其他员工接口响应不含主题、联系人和联系方式。
- 停用、重置密码、角色变更会撤销账号会话；用户改密撤销全部会话并重新登录。管理员管理操作保留至少一个启用的管理员。
- 预订创建、审批、拒绝、取消和过期均在事务内生成站内通知。通知列表显示最近 100 条；操作记录显示最近 100 条。

## 运行

开发：`npm run dev`，源文件变更自动重启后端。构建：`npm run build`，运行：`npm start`。

迁移：`npm run db:migrate`。初始化：`npm run setup:local`，只补齐缺失账号和会议室，不清空已有数据。编译后的迁移入口为 `node --env-file=.env dist/migrate.js`。

备份：`npm run db:backup`。备份恢复验证：`npm run db:verify-backup`。复用 `~/jonge/infra` 的 PostgreSQL，只操作本项目数据库及临时验证库。

当前交付覆盖本地独立运行的会议室管理流程；企业 SSO、外部邮件/日历同步、多时区和楼层平面图属于后续扩展。
