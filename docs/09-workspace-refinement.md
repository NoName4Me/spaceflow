# 会议室选择与管理调整

## 当前行为

- 屏幕和白板仍可添加、移动、旋转和调整尺寸。
- 布局管理维护共享布局，支持新增、复制、编辑、导入导出和历史版本。
- 会议室选择一个布局；发现页的宫格、列表缩略图和详情弹窗均使用该布局预览，容量独立设置，不按图中椅子数量计算。
- 会议室管理保留楼栋、楼层树，右侧采用表格展示容量、面积、布局、设施、规则和状态。
- 可选择当前层的全部会议室或勾选部分会议室进行批量修改。仅勾选的属性写入；未选字段、未选会议室、原有权限与预订保持不变。提交遇到失效资源时整批回滚。
- 批量可改容量、面积、布局、设施、预订方式、开放状态、周期开关及所属楼层；随后可单独编辑个别会议室。
- 移除页面顶部的大标题、英文标识和说明性副标题，只保留导航位置及必要操作。
- 移除发现页图例、重复空闲文案、详情按钮等冗余内容。宫格和列表整条可点击，也可键盘打开详情弹窗，再发起预订。
- 宫格/列表偏好保存在当前浏览器；列表始终保留布局缩略图。

## 数据与验证

新增迁移 `007-layout-library.sql` 和 `008-template-history.sql`，将现有会议室按布局类型关联到预置布局。原会议室、预订和历史布局数据保留。

新增批量编辑与共享布局接口测试，覆盖权限、输入校验、原子性、未选属性保留、模板预览和版本冲突。浏览器验收覆盖新增布局、屏幕/白板调整、导入与恢复、同层全选批量修改、单独覆盖、两种发现视图、详情弹窗、键盘操作与预订。

检查：`npm run typecheck`、`npm test`、`npm run test:ui`、`npm run build`、`npm run verify:setup`。当前能力以本记录和 README 为准，早期文档保留历史状态。

本轮通过 28 项接口测试与四套浏览器验收，并对批量管理、布局编辑和发现列表执行无障碍扫描。
