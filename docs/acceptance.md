# 验收与测试

## 自动检查

```bash
npm run typecheck
npm run build
npm test
npm run test:ui
npm run test:prototype
npm run verify:setup
npm run db:verify-backup
```

| 命令 | 范围 |
| --- | --- |
| `typecheck`、`build` | 前后端 TypeScript 检查、服务与 Vite 前端构建 |
| `test` | 真实 PostgreSQL 接口、周期规则与本地 SMTP 验证 |
| `test:ui` | 登录、管理、周期、改期、批量编辑、布局和发现页浏览器验收 |
| `test:prototype` | 保留的原型规则与六页面冒烟检查 |
| `verify:setup` | 临时空数据库全量初始化 |
| `db:verify-backup` | 临时数据库备份恢复 |

浏览器验收在本机使用 Google Chrome，CI 使用 Chromium。测试创建独立记录并清理，截图位于 `test-results/`。初始化及恢复验证复用本地基础环境，只创建和删除临时验证库。

当前覆盖 32 项接口/规则/邮件测试与六套浏览器流程。React 迁移检查另外覆盖焦点保留与循环、受控输入、SVG 拖拽/缩放/撤销、导入导出、快速切换日程时的过期请求取消，以及会话失效后关闭管理表单。CI 配置在 `.github/workflows/ci.yml`，推送或创建拉取请求后触发。

详情预订记录另外检查倒序、分页、备注创建/修改、真实预订人、隐藏信息过滤和四个日期快捷筛选。

## 人工验收路径

| 角色 | 路径与结果 |
| --- | --- |
| 员工 | 空间发现 → 筛选 → 宫格/列表切换；列表应保留布局缩略图 |
| 员工 | 点击条目 → 详情弹窗 → 预订；关闭弹窗后保留原列表位置 |
| 员工 | 创建周期预订 → 检查冲突日期 → 明确选择是否跳过；新增未确认冲突应拒绝整批提交 |
| 员工 | 我的预订 → 修改本次或后续 → 改期；检查冲突回滚、旧记录与例外保留 |
| 管理员 | 会议室管理 → 选择楼层 → 全选或勾选 → 批量编辑；只修改勾选属性，随后可单独覆盖个别会议室 |
| 管理员 | 布局管理 → 新增/复制 → 编辑屏幕、白板 → 保存 → 分配到会议室；用户端应展示共享预览 |
| 管理员 | 布局导入与历史版本载入 → 保存 → 刷新，检查回显与过期版本冲突 |
| 管理员 | 账号与部门 → 分配部门、配置可见/可订规则；用员工账号检查列表和接口限制 |
| 管理员 | 预订审批 → 通过/拒绝本次或系列；预订管理 → 代订或取消 |
| 全员 | 通知 → 已读；账号设置 → 改密并重新登录；管理员检查操作记录 |

## 核心一致性检查

- 100 个同房间重叠并发请求，最多一条有效预订；相邻时段允许。
- 取消、拒绝与过期释放占位；未开始的有效预订才允许修改。
- 仅修改文字不延长待审批期限；过期申请不能通过编辑恢复。
- 周期创建、系列改期、批量房间修改出现失败时不留下部分写入。
- 批量修改保留未选字段、未选房间、权限与原预订；普通员工不能调用管理接口。
- 隐藏详情不在其他员工的响应中暴露主题、联系人或联系方式。
- 房间预览来自所选共享布局，容量不依赖图中的椅子数量；正在使用的布局不能直接删除。
- 邮件发送失败不阻止预订，任务可退避重试；以本地 SMTP 接收端验证实际协议投递。

## 性能与可访问性

已有 100 间资源、1000 条日程的分页测试：20 间资源的一页包含 200 条日程，本机测试约 5 毫秒，仅代表该测试环境。

浏览器测试对管理表格、布局编辑、日程、发现列表和详情弹窗执行 WCAG 2 A/AA、2.1 AA 自动扫描，并验证键盘打开、关闭弹窗和按钮/数值编辑入口。自动扫描不等于完整人工读屏验收。

移动视口检查发现页及层级管理。复杂 SVG 触摸编辑和多浏览器兼容性尚未完成全面验证。
