# 间序 · Spaceflow

会议室管理与预订平台。按楼栋、楼层管理会议室，支持容量与设施筛选、共享布局预览、单次与周期预订、审批和权限控制。

办公空间模块新增园区、楼栋和楼层地图、2D/3D 浏览及布局管理。产品范围与后续路线见 [办公空间 2.0](docs/workplace-v2.md)。

## 启动

需要 Node.js 22.12+、Docker，以及 `~/jonge/infra` 中运行的 PostgreSQL。

```bash
npm ci
npm run setup:local
npm run deploy:local
```

访问 [Spaceflow](http://127.0.0.1:3080)。初始账号密码保存在 `.local-accounts`，可登录后修改。首次初始化自动提供完整办公空间：园区、建筑、楼层、部门、人员、工位、会议室和预订记录。界面按普通业务数据呈现；它们是用于体验的初始化内容，正式企业环境请使用实际资料。重复初始化不覆盖已有账号、布局、会议室或预订。已有业务数据时默认跳过丰富初始化；需要显式新增独立办公场景时，运行 `npm run db:migrate && npm run db:seed:workplace`（不覆盖原记录，建议先备份）。

## 主要功能

- 楼栋 → 楼层 → 会议室三级管理，右侧列表预览，支持选择属性进行批量编辑。
- 宫格/列表切换，列表保留布局缩略图，点击会议室直接打开详情弹窗。
- 布局管理支持新增、复制和编辑屏幕、白板等组件；用户端显示所选共享布局的预览图。
- 单次或每天、每周、每月预订，支持指定星期、冲突预览、改期及系列后续修改。
- 全局 AI 对话抽屉，支持历史对话、时间与设施组件、会议室推荐卡片及单次冲突替代；严格满足已确认条件，支持配置兼容 OpenAI 的模型服务。
- 会议室级可见与可订权限、审批占位、隐私过滤、管理员代订。
- 账号与部门管理、站内通知、可配置 SMTP 邮件、操作记录。

## 技术栈

React 19、TypeScript、Vite、CSS 主题变量与 SVG；后端使用 Express 5、Zod、PostgreSQL，Docker Compose 部署。
